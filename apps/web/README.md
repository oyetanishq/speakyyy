# web

The pdf-speak front end: Vite 8, React 19, TypeScript 6, Tailwind v4 and oxlint.

See the [root README](../../README.md) for features, architecture and deployment.

```sh
pnpm dev      # dev server
pnpm build    # type-check + production build
pnpm lint     # oxlint
pnpm preview  # serve dist/
```
